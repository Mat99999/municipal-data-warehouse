# Data notices and attribution

The software is MIT licensed. Data retains the terms of its publisher.

- **SCB / Statistics Sweden:** open data in the Statistical Database is available under CC0. Source attribution is still retained in lineage for transparency. <https://www.scb.se/vara-tjanster/oppna-data/>
- **Kolada / RKA:** use is free and commercial use is allowed. Attribute Kolada when presenting unmodified source data. Do not label transformed calculations as if Kolada produced them. <https://www.kolada.se/om-oss/api/>
- **Valmyndigheten:** data is free to use provided Valmyndigheten is named as source. <https://www.val.se/valresultat-och-statistik/statistik-och-data/om-var-oppna-data>

The committed fixture values are synthetic contract examples created for this repository. They are not official statistics and must not be used for substantive conclusions.
